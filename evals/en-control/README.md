# English control items

20 English items (10 light, 10 everyday) parallel to items in `evals/zh-tw/`;
each item's `notes` names its zh-TW counterpart. `scripts/eval_models.py` runs
them with the zh-TW set and reports the difference between a model's English
and zh-TW pass rates as `zh_tw_gap`.

Twenty items are a rough reference, not a measurement: one item is 5 points.
Same format, scoring, authorship and licence as `evals/zh-tw/README.md`. Like
that set, these were written by an AI model and have not been reviewed by a
person.
